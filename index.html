Android Installation

Android 7.0+
  1. Tap Get Access Key in the header and copy your key.
  2. Download SigmaGallery.apk above.
  3. Open the file and enable Install from Unknown Sources if prompted.
  4. Launch SigmaGallery and paste your key to unlock.
MIN RAM: 2 GB STORAGE: 30 MB

Windows PC Installation

Win 10 / 11 (x64)
  1. Generate your key via the Get Access Key link.
  2. Download SigmaGallery.exe above.
  3. If Windows SmartScreen appears, click More info → Run anyway.
  4. Enter your activation key on the startup screen.
MIN RAM: 4 GB STORAGE: 60 MB
